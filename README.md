To launch the project (tested on Ubuntu 24.04 and ROS2):

 - open a new terminal
 - run "git clone --recurse-submodules https://github.com/michelezarantonello/ws_group_32_assignments/"
 - change directory to the workspace folder ws_group_32_assignments
 - Build the workspace with "colcon build"
 - Source the last building with "source install/setup.bash"
 - Launch the nodes with "ros2 launch group_32_launch my_launch.launch.py"

From the opened terminal all the outcomes are visible.
